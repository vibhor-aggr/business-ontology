# Business Ontology Documentation

Static HTML documentation for a business ontology covering procurement,
supplier management, supply-chain issues, procurement systems, organizational
stakeholders, value dispositions, and compliance-related concepts.

## Repository Layout

- `index.html` is the main generated documentation entry point.
- `contents.html` and `index-all.html` provide generated navigation views.
- `classes/` contains ontology class documentation.
- `objectproperties/` contains object-property documentation.
- `dataproperties/` contains datatype-property documentation.
- `individuals/` contains named individual documentation.
- `datatypes/` contains datatype documentation.
- `ontologies/` contains ontology-level documentation.
- `css/`, `js/`, and `images/` contain static assets used by the generated
  documentation pages.

## Usage

Open `index.html` in a browser to browse the ontology locally. The repository
can also be served as a static site with any basic HTTP server.

## Notes

The repository contains generated documentation artifacts. No application server
or database is required to view the ontology pages.
